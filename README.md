# Arcline

Arcline is a "proof-of-work for builders" platform.

Builders create **projects**, then log **entries** (such as WIN, SETBACK, MILESTONE, or REALIZATION) as they build. 
It is a journaling and showcase tool — NOT a productivity tracker. Builders come when they have something to log, without any daily obligation.

**Key philosophy:** We celebrate the _journey_, not just the destination. Setbacks are not failures — they are valuable data points.
